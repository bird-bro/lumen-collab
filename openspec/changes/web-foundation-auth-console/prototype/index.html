布局度量(OPS 三区壳层)

三区结构(OPS layout/index.vue):左 68px 图标导轨(#0B2540 近黑科技蓝,修订 11) —— 一级菜单 (系统管理 + 放射科/超声科/内镜科,图标 26px + 下方短标签 ~16px, 图标与标签均为纯白 #fff(OPS --mainnav-color),选中 #0E7C86 / 悬停 #12355C, logo 块与头部同高 60px);60px 白色头部横跨导轨右侧 —— 左产品标题 (26px/600)+ 环境占位 + 右用户区(用户名/所属机构双行 + 50px 圆头像,悬停弹出 基本信息与 plain 大按钮「退出登录」,无 caret;不含 OPS 的问题反馈/客服/聆听图标); 头部下方 = 160px 白色二级侧栏 + 内容区。 侧栏渲染激活一级的 children(修订 7 结构):二级目录 = 分组标题 (16px 灰字 + 20px 组图标,保留图标),三级页面 = 组内平铺行项 (18px 字号 / 40px 行高,纯文字、无图标 —— OPS SidebarItem 条件渲染, 实际菜单数据无 icon),组间 1px 分隔线;一级永不进侧栏,只在导轨;选中态 = 青色左条 + 浅青底(修订 5)。 折叠交互(修订 9,OPS 形态):展开态 = 24px Fold 图标绝对定位于侧栏右下角 (right:4px / bottom:0 / padding:5px,无文字);收起态 = 40px 宽竖条 (Expand 图标 + 竖排文字 18px/600,逐字换行),整条可点击展开。 列表页无页头标题块(OPS 紧凑风格),页面身份 = 侧栏选中项;工具行 = 查询组件(左)+ CirclePlus 新增钮(右);操作列 = 纯图标链接钮(tooltip 出文案), 表头「操作」右侧带刷新图标;分页行水平居中(高 60px,OPS .hpage-pagination); 内容区 padding 10px(修订 8,用户指定)。 侧栏配色(修订 10):青色底实验(修订 9)经用户裁定不采用,回退白色; 选中态保留青色系 —— 青色左条 + 浅青底 #E6F6F7 深青字。
