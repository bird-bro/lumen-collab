## Design Constraints

- **Architecture/Decisions**: `LogoUploadField` mirrors the `RegionSelects` form-bind
  precedent (`Form.useFormInstance`; AntD `Upload` cannot natively bind a bare string);
  `maxCount 1` + `accept="image/*"` + `beforeUpload` gate returning `false` (uploads
  driven by `customRequest`, never the default action poster); form value set ONLY on
  upload success (failed upload keeps the stored value); `PROFILE_FIELDS` keeps the
  remaining five Input fields, `logoUrl` gets its own labeled Form.Item beside the 地区
  cascade; backfill (`openDialog`) and submit body assembly unchanged — the wire
  contract's `logoUrl` field persists.
- **Technical constraints**: never-modify rule — `apiRequest` public behavior stays
  byte-identical (its unit tests pin it; only a NEW export `apiUpload` is added);
  TypeScript strict; AntD 5 components first + design tokens (no ad-hoc hex); no mock
  layer at runtime — tests stub the `@/api/*` seam only; backend-first: this change
  applies after `org-logo-upload-api` is user-verified.
