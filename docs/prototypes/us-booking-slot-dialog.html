现状：预约时间 = 内联 DatePicker + Select 两格，下拉里只有「已满 n/n」，整天号源分布不可见，三列紧格里局促。 本案：单元格收敛为 一个预约触发钮，点击弹出 选择预约时段 弹框 —— 日期导航 + 分组时段网格，每档号源分段计 + 余量数字； 预约仅约明天起，默认落明天（今天 = 直接登记即到即检，不进弹框）。 契约不变：仍走 GET /orders/slot-options?date&modality，提交值仍为档位 START；清除 = bookingTime=null（即到即检）。

壹表单触发态

预约时间单元格的三种 resting 形态。触发钮 = calendar-check icon（aria-label=选择预约时段）+ 摘要文字； 日期与时段成对，已选形态带 hover 清除钮（清除 = 回到即到即检）。label/字号沿用现行 Field 定式（88px 右置）。

预约时间 未开通预约
未开通预约：该模态无预约配置（configured=false），触发钮禁用，fail-closed 语义与现行一致；现场 walk-in 不受影响。
预约时间 即到即检（点击预约）
即到即检（默认）：已配置但未选时段。点击触发钮打开弹框；不选时段直接提交 = 现场 walk-in，bookingTime=null 不变。
预约时间 周二11-25 09:00–09:30
已选时段：摘要 = 星期 + 日期 + 档位区间（等宽字体）。再点触发钮可改选；× 清除即回到即到即检。
贰选择预约时段弹框

默认落在明天；今天不可选（今天 = 外页直接提交登记即 即到即检，月历上灰显注明）。 全交互演示：‹ › 翻日 / 点日期条开迷你月历 / 点时段格选档（再点取消）。每档卡 = 档位区间 + 号源分段计（一格 = 1 个号，实心 = 已约、空心 = 空位）+ 余量数字； 灰档已满禁选、橙档仅剩 1 号（空心格呼吸提示）。顶部汇总条给整天的 剩余/总号 一眼数。实现时用 antd Modal + token，原型手写样式仅定形态。

叁拍板点

待拍板后落提案（改写 us-booking-slot-picker-web 的 Select 方案段；后端 us-booking-slot-picker-sev 不动）。

触发控件：预约时间两格（DatePicker+Select）收敛为一个 icon+摘要触发钮；label 预约时间保留。已选摘要 = 周X MM-DD HH:mm–HH:mm。
预约日期域 = 明天起（D+1，拍板 2026-11-24）：弹框默认落明天；今天不在弹框可选 —— 今天直接在登记页提交登记 = 即到即检；月历上今天灰显 + tooltip 注明，‹ › 下边界 = 明天。
弹框内选日：迷你月历常驻显示（‹ › 翻月；2026-11-24 中途拍板，反转原「不做角标」）；每个可选日带日级余量角标（余 N / 满）= 前端对展示月未来各日并行拉 per-date 端点聚合，专用日级 range 端点留作后续优化。
号源可视化：每档卡 = 区间 + 分段计（1 格 = 1 号，实心已约/空心空位）+ 余量数字；已满灰禁选、仅剩 1 号橙 + 空心格呼吸。capacity 过大（>10）时退化为进度条。
语义不变：日期时段成对提交（选档即用弹框当前日期）；清除/不选 = 即到即检 bookingTime=null；提交值仍为档位 START HH:mm；configured=false 触发钮禁用；A0400 满员后端校验不动。「预约 ≥ 明天」为前端约束，后端是否同规则校验另行提案。
范围：过去时段标灰被 D+1 下限自然覆盖（弹框内不存在过去日，DB-clock 增强不再紧迫）；预约设置页（exam-slot）不动；aria 锚点 —— 触发钮 aria-label="选择预约时段"、弹框 role="dialog"、时段格 role="button" + 全量摘要文案（页测子串锚定）。
