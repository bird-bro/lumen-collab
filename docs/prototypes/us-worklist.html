贰 · 范围注记与登记页宽态的分工 + 行为口径
与登记页宽态分工：登记页 rail 宽态是登记单维度查询（建单场景）；本页是全生命周期检查列表（接诊 / 报告 / 打印场景）。两张表并存各有入口——工作站菜单 = 登记台 + 诊断列表 两项，诊断页无菜单项。
chips 多选叠加：状态 chips 支持多选（EIS checkbox 组同构），「全部」点击互斥清空其它；「已打印」是 已完成 ∩ 打印过 的子集过滤，不新增单据状态（诊断页原型同款口径）。
行交互：双击行 = 诊断（EIS 同构）；已完成行双击 = 报告预览。操作列固定右缘（sticky），窄屏横向滚动不被遮。EIS 操作列里的 收藏/详情 不搬（见诊断页原型范围外）。
复用件：我的查询 = 登记页 search-filters API（后端按 uid 持久化 + 设默认）；列设置 = localStorage 记忆（EIS useHeaderColumn 同款）；自动刷新 5s 轮询开关 = 诊断页 rail 同款。呼叫按钮为占位，内核叫号域立项时接通（提交/放弃联动 finish 的联动点已在诊断页原型记档）。
查询字段取舍：EIS 的 登记号（checkinNo）不搬——lumen 编号锚点 = 影像号 / 检查号；补 申请科室 / 申请医生（HIS 申请单三元组，us-apply-info 已落）与 仅急诊 / 仅孕检 快捷开关。诊断时间区间 = 报告域提交时刻。
状态胶囊色：待诊断=蓝 / 诊断中=橙 / 已完成=绿 / 已打印=灰（登记页、诊断页两原型同款）；锁定的橙色 chip 带锁定人（我 · 锁定 / 锁定 · 李医生）。
叁 · 拍板点列表页自身的三件事
DECISION 01

列表打印入口

A 列表直接预览打印B 跳诊断页打印

A：已完成行「预览/打印」就地弹只读预览层（EIS preview-and-print 形态）——诊断页此时可能被他人锁定，打印不该依赖锁。B：跳书写工作台打印，交互重且要抢锁。

建议：A（只读打印通道与书写锁解耦）
DECISION 02

强解权限

A 仅系统管理员B 科室负责人也可

诊断中报告被锁定（EIS isLock 行级锁），EIS 有管理员强解接口 /api/rep/unLock。A：强解挂系统管理权限位；B：科室负责人权限位也能解，现场周转更快但越权风险高。

建议：v1 A（权限位复用现有按钮级 perms，B 等科室角色细化）
DECISION 03

默认查询口径

A 今日 + 待诊断B 今日 + 全部状态C 近 7 天全部

进页第一眼：A = 接诊视角（今天要看的单子），历史核对用「全部」chip 或 我的查询 方案；B = EIS 形态（今天全量）；C = 跨天核对（吴桐 昨日登记今日完成 的场景）。

建议：A 默认，我的查询方案里预置「近 7 天全部」兜底
